A few demo pages for using the @techandsoftware/teletext module.

  • ES6 module import - this is the preferred way of using the module. The page shows importing the module, setting the g0 character set and loading a test page. It also shows using the event API
  • UMD module import - the UMD module is the older way for browsers that don't support ES6 module imports. Realistically, this is only needed for Internet Explorer. However, since IE won't support the ES6 syntax used in the code, then you will need to arrange for your own transpiling to make the module compatible for IE or for other browsers that you need to support
